What a customer does

Pay in the shop from a bank account

1Choose a product and sign in once at the central login
2Pick a bank at the hub: it opens the bank's confirmation page
3Confirm with no second login: the money moves bank to bank
4Back in the shop, the order is marked paid

Accounts and balance

Every account, balance and recent transfer on one dashboard.

Transfers

Inside the bank or to any bank connected to the hub.

Payment cards

Issue, edit and delete cards, then pay online with them.

Direct payments

Pay merchants from an account, with no card details.

Shop cabinet

Orders, products with uploaded images, payment reminders.

Administration

All accounts and a transfer lookup for bank staff.

Three independent stacks

Bank

ASP.NET Core · SQL Server
  • Bank web app
  • CentralApi hub
  • Ocelot gateway, rate limit
  • nginx entry

Shop

FastAPI · PostgreSQL
  • React shop + cabinet
  • Python API
  • Redis sessions
  • MinIO images

KYC

Keycloak · H2
  • Login and register
  • Edit profile
  • Change password
  • Single sign-on
Security built in: passwords live only in Keycloak, internal services publish no ports, and changing a profile or password signs the user in again everywhere.
